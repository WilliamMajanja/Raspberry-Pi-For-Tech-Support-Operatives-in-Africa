# Source and Build Appendix

The printed and EPUB editions include a generated source appendix so the utilities and book-build infrastructure can be examined offline. The appendix is assembled from the exact source files used for each build; generated PDFs and EPUBs are not embedded in themselves.

The appendix includes FieldKit, the Coffee Pot Snake generator, portal integration, tests, original field-support and Informatics diagrams, publication CSS/assets, service configuration examples, build-tool pins, CI workflow, and license texts. Sample configuration files contain placeholders only. Never put production keys, user ciphers, or personal data in this repository.

The source appendix is documentary: code shown here is not executed by opening the book. See each component's README and the coverage page for prerequisites and test status.
