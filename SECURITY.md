# Security Policy

This repository is a documentation project; it does not ship a security application. Security issues in a linked upstream tool should be reported to that project through its own published disclosure channel, not attributed to this guide.

## Reporting a problem in this guide

For a privacy concern, accidentally exposed secret, unsafe command, or other security-sensitive documentation issue, do not post the sensitive material in a public issue. Contact the repository maintainer through the private reporting option on GitHub if enabled. Otherwise, open a minimal public issue that describes the affected page without including secrets or exploit details, and ask for a private channel.

This repository has no published response-time guarantee. If an issue affects a third-party project, contact that project’s maintainers directly.
