# Code of Conduct

This project is part of the Hack with Raspberry Pi community. We aim to make technical learning respectful, safe, and welcoming to people with different backgrounds, experience levels, languages, abilities, and access to equipment.

## Expected conduct

- Be respectful and constructive; criticize ideas and documentation, not people.
- Make space for questions and different levels of experience.
- Respect privacy, confidentiality, and cultural context. Do not publish another person’s data, contact details, or field information without consent.
- Keep technical examples within authorized, safe, and clearly described scope.
- Give accurate credit and follow source licenses.

Harassment, discrimination, threats, doxxing, and deliberate unsafe conduct are not acceptable. If a concern arises, contact the repository maintainer through an appropriate private channel or report mechanism. Project maintainers may edit or remove content that violates this code or creates an immediate risk.
