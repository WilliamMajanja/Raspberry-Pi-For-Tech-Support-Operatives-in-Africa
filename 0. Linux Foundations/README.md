# Linux Foundations

These chapters provide the operating-system and shell knowledge needed to support Raspberry Pi and Linux systems thoughtfully. They apply to Raspberry Pi OS, Debian, and Kali where noted; distribution-specific commands are labeled.

## Platform tested for this edition

The authoring desktop is Debian GNU/Linux 13 (Trixie), ARM64, KDE Plasma 6.3.6 under Wayland. Commands described as *verified on the authoring system* are limited to that environment. A Debian result does not establish that a Kali-only package or workflow works on Kali, and vice versa.

Kali is a Debian-derived distribution with its own repositories, packaging, defaults, and release process. **Do not add Kali repositories to a Debian installation** to obtain a Kali package. Use a supported Kali virtual machine, dedicated device, or isolated lab when a lesson specifically requires Kali.

The book itself is plain GitHub-flavored Markdown. No book builder or third-party documentation package is required to read it on GitHub.
