# External Security Resources — Historical Index

The original curated list of external repositories is retained in [Awesome Lists](Awesome_Lists.md). It has not been revalidated as a current recommendation list. Before installing or running a linked project, check its current maintenance status, release provenance, license, dependencies, and safe operating instructions. A link is not an endorsement or security review.

For maintained platform documentation, start with [Kali’s official docs](https://www.kali.org/docs/) and [Debian’s documentation](https://www.debian.org/doc/).
